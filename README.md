# ACM QUEST AI/ML - Resource Guide


# Important Note Before Starting

You are **not expected** to complete every single resource fully.

These resources are meant to complement each other. Different resources explain concepts differently, so feel free to switch between them whenever required.


# Recommended Learning Order

## 1. Python & Libraries Prerequisites

Before starting Machine Learning properly, make sure you are comfortable with:

* NumPy
* Pandas
* Basic data handling

### Resource

* [Dataset Manipulation and Visualisation](https://jakevdp.github.io/PythonDataScienceHandbook/)

Focus on:

* Arrays and matrix operations
* DataFrames
* Indexing and slicing
* Basic data manipulation

---

# 2. Mathematics for Machine Learning

A strong mathematical foundation makes ML significantly easier to understand.

## Linear Algebra

### Resources

* [Linear Algebra](https://github.com/acmsnu/AI-ML-QUEST-2026/blob/main/Elementary%20Linear%20Algebra%20(Ron%20Larson).pdf)

* [3Blue1Brown – Linear Algebra Playlist](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab)

### How to Use Them

Use the 3Blue1Brown playlist first to build intuition visually.

After developing intuition, use the Linear Algebra book for deeper understanding and practice.

Focus mainly on:

* Vectors
* Matrices
* Matrix multiplication
* Linear transformations
* Eigenvalues and eigenvectors
* Dot products

Do not get stuck trying to master every topic perfectly before moving ahead.

# How to Effectively Use the ML Resources

## Hands-On Machine Learning

This should primarily be used for:

* Practical implementation
* Understanding workflows
* Learning libraries and coding practices

Do not just read the book passively. Implement everything alongside it.

---

## Andrew Ng CS229

This resource is more theory and mathematics focused.

Use it to:

* Build strong conceptual understanding
* Understand why algorithms work
* Learn the mathematical intuition behind ML

You do not need to understand every derivation perfectly initially.
